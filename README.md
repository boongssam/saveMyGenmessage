# 쪽지보관함 (Gen Messenger 쪽지 영구 보관)

Gen Messenger는 오래된 쪽지를 지웁니다(이 PC 기준 약 5개월). 이 도구는 메신저의 쪽지 DB를 **읽기만** 해서
내 PC의 보관함(`C:\쪽지보관함`)에 계속 쌓아 두고, 브라우저에서 검색해 볼 수 있게 합니다.

## 사용법
- **보관함 열기:** 바탕화면의 **쪽지보관함** 아이콘을 더블클릭합니다. 처음 열 때 비밀번호를 정합니다.
- **자동 수집:** 로그인 2분 뒤, 그리고 매일 16:00에 자동으로 새 쪽지를 가져옵니다.
  PC가 꺼져 있었다면 다음에 켤 때 따라잡습니다. 화면의 **지금 가져오기** 버튼으로 바로 가져올 수도 있습니다.
- **검색:** 제목·내용(여러 단어는 모두 포함), 보낸/받는 사람, 기간, 첨부 여부로 찾습니다.
- **저장:** **엑셀로 저장**은 현재 검색 결과를 CSV로 저장하고, 쪽지의 **인쇄 / PDF**는 한 건씩 인쇄하거나 PDF로 저장합니다.
- **잠그기:** 자리를 비울 때 누르세요. 8시간 동안 사용하지 않으면 자동으로 잠깁니다.

## 보관되는 것
| 항목 | 설명 |
|---|---|
| 받은·보낸 쪽지 | 제목, 보낸/받는/참조 사람, 시각, 본문(원본 서식 그대로) |
| 읽음 확인 | 보낸 쪽지를 누가 언제 읽었는지 |
| 첨부파일 | 메신저에서 **내려받은 적이 있는 파일만** 보관됩니다. 나머지는 이름만 남고 "미보관"으로 표시됩니다. |

메신저에서 쪽지가 지워져도 보관함에서는 지워지지 않습니다.

## 폴더 구성 (`C:\쪽지보관함`)
- `archive.db`: 보관함 본체
- `files\`: 보관된 첨부파일
- `backups\`: 매달 1번 자동으로 만드는 보관함 백업 (USB 등에 옮길 때는 암호화된 압축 파일로 저장하세요)
- `logs\`: 수집 기록
- `auth.json`: 비밀번호 확인용 값 (비밀번호 자체는 저장되지 않음)

## 문제가 생기면
- 수집이 실패하면 바탕화면에 **쪽지보관함 수집 오류.txt**가 생깁니다. 다음 수집이 성공하면 자동으로 지워집니다.
- 메신저가 업데이트되어 DB 구조가 바뀌면, 보관함을 보호하기 위해 수집을 멈추고 위 파일로 알려 줍니다.
- **비밀번호를 잊었을 때:** `C:\쪽지보관함\auth.json`을 지우고 보관함을 다시 열면 새로 정할 수 있습니다.

## 설치 / 제거 / PC 이전
- 설치(다시 설치): `powershell -ExecutionPolicy Bypass -File scripts\install.ps1`
- 제거: `powershell -ExecutionPolicy Bypass -File scripts\uninstall.ps1` (보관함 데이터는 지우지 않음)
- PC를 옮길 때: 이 폴더와 `C:\쪽지보관함` 폴더를 새 PC에 복사한 뒤 설치를 실행합니다. Node.js 22.13 이상이 필요합니다.

## 개발자용
- `npm run collect`: 수집 1회 실행
- `npm start`: 보관함 화면 서버 실행 (http://127.0.0.1:8765, 이 PC에서만 접속 가능)
- `npm test`: 수집기 테스트
- 설정: `config.json` (메신저 경로, 보관함 경로, 포트, 자동 수집 시각)
